# Dimet static site

Static website for Dimet d.o.o., a Slovenian industrial supplier. Plain HTML
pages generated by a Python script, styled with Tailwind CSS 3, with a small
vanilla JS file for navigation and product search/sort.

## Rebuild

    npm install
    npm run build        # runs scripts/build_site.py, then builds CSS
    npm run build:css    # CSS only (src/input.css -> css/site.css)

Requires Node.js and Python 3. Open index.html in a browser or serve the
folder with any static file server.

## Structure

- data/content.json  - all site content (pages, products, news)
- scripts/           - build_site.py, renders HTML from content.json
- src/input.css      - Tailwind entry and component classes
- css/site.css       - built, minified CSS (generated)
- js/site.js         - mobile nav, product search and sort
- images/            - site images
- izdelki/, novice/, strani/ - generated products, news and page HTML
- tailwind.config.js - design tokens (colors, font, container width)

## Content source

Content lives in data/content.json. It was generated from the WordPress export
of dimet.si (an All-in-One WP Migration .wpress backup). Edit the JSON and
rebuild rather than editing generated HTML by hand.

## Design notes

One type family (Inter), 4/8px spacing, AA contrast on all text pairs, visible
focus rings, touch targets of at least 44px, mobile-first layout.
